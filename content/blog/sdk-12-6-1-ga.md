![Titanium SDK 12.6.1.GA](/blog/titanium-general.png)

This version fixes a bug with click events on iOS that was introduced in 12.6.0.GA.

For a more detailed overview and all changes, see the release notes: [Titanium SDK 12.6.1.GA Release Note](/docs/sdk/12.6.1/release-notes).

In case you've missed the 12.6.0.GA release notes please check this link: [Titanium SDK 12.6.0.GA Release Note](/docs/sdk/12.6.0/release-notes).

## Install

**Follow these steps to get SDK 12.6.1.GA:**

1. Install the CLI with `[sudo] npm i -g titanium alloy`
2. Run `titanium sdk install 12.6.1.GA`
3. Set `<sdk-version>12.6.1.GA</sdk-version>` in your `tiapp.xml`
